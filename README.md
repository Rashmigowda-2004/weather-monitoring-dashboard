# 🌦️ Weather Monitoring Dashboard

A real-time weather dashboard built with Python and Streamlit.

## Features
- Live weather data from OpenWeatherMap API
- Current temperature, humidity, wind speed
- 5-day temperature forecast graph
- Interactive map with city marker
- Search any city worldwide

## Tech Stack
- Python, Streamlit, Plotly, Folium
- OpenWeatherMap API
